# 圖資中心測試與驗收清單

## 建置

- [ ] 使用乾淨環境執行 `npm ci` 成功。
- [ ] `npm run lint` 無錯誤。
- [ ] `npm run build` 無 TypeScript 錯誤並產生 `out/`。
- [ ] 子目錄 base path 下 JS、CSS、圖片無 404。

## 功能

- [ ] 七種身分切換後，必辦流程與條件任務正確更新。
- [ ] 重新整理後只保留 student type，不保存個資。
- [ ] 每一個 actionUrl、detailUrl 均連到正確官方頁面。
- [ ] 外部網址以新視窗開啟並具 `noopener noreferrer`。
- [ ] 身分查詢視窗可用 X、背景與鍵盤操作關閉。
- [ ] FAQ 與手機選單可正常操作。

## 響應式與無障礙

- [ ] 375、390、430、768、1024、1440px 無水平捲動。
- [ ] 所有按鈕可用鍵盤操作，焦點清楚。
- [ ] 圖片 alt 正確，狀態不只靠顏色。
- [ ] 文字放大至 200% 仍可操作。
- [ ] 使用 Lighthouse／axe 檢查基本 WCAG 2.1 AA。

## 資安與個資

- [ ] 公開檔案沒有 API key、密碼、內網位置或個資。
- [ ] Web Server 已設定 HTTPS 與必要安全標頭。
- [ ] 身分查詢未串接前不傳送輸入；正式串接前完成個資評估。

## 維運

- [ ] 有 staging 與 production 環境。
- [ ] 保存前一個可回復版本。
- [ ] 已指定系統管理員、總編、各程序 Owner 與審核者。
- [ ] 每學年度有資料盤點、複核與封存時程。
