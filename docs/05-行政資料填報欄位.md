# 行政單位資料填報欄位

## 程序主檔必填

- 程序 ID（由網站總編管理）
- 行政業務名稱
- 給學生看的程序名稱
- 一句話輔助說明
- 開始日期、截止日期
- 立即辦理網址 actionUrl
- 詳細說明網址 detailUrl
- 資料負責單位 dataOwner
- 承辦單位、承辦人、電話、分機、Email、辦公地點
- 應備資料、注意事項
- 官方來源或公文依據
- 最後確認人、確認日期、確認狀態

## 身分 × 程序規則

每一種 studentTypeId 對每一個 taskId 必須選擇：

- 必須辦理 required
- 依情況辦理 conditional
- 選擇性 optional
- 不適用 not_applicable

若只有某一招生管道的日期或網址不同，請新增 admissionTypeId 規則，不要複製整套學生身分。

## 填報注意

- actionUrl 與 detailUrl 不可填成同一個模糊入口，除非確實只有一頁。
- 不可填 Google 搜尋結果、縮網址或個人雲端連結。
- 日期使用 `YYYY-MM-DD`。
- 電話、Email 需確認學生可直接聯繫。
- 若資訊尚未確定，保留待確認，不可用前一學年度資料猜測。
- 正式填報 Excel 應與此欄位一致，未來才能轉成 JSON、CMS 或 API。
